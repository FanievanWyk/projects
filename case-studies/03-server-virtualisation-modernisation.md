# Server & Virtualisation Modernisation

## Context

Production services were hosted on ageing infrastructure and an older Windows Server generation. The environment required a more supportable platform with improved resilience and capacity.

## Challenge

Support the transition to new server infrastructure and a clustered Windows Server virtualisation platform while protecting service availability and data integrity.

## Environment summary

- Two-node Hyper-V cluster
- Windows Server 2022
- 13 production virtual machines
- Network-attached storage, LUN, and iSCSI services
- Mixed operational workloads and dependencies

## My role

- Contributed operational knowledge and infrastructure requirements
- Supported hardware, storage, networking, and service preparation
- Assisted with migration sequencing and dependency planning
- Validated services and supported issue resolution
- Continued administration and lifecycle management after migration

## Approach

1. Mapped workloads, dependencies, storage needs, and operational priorities.
2. Prepared the surrounding network, storage, identity, backup, and monitoring requirements.
3. Sequenced migration work to minimise disruption and preserve rollback options.
4. Validated each workload at both infrastructure and user-service levels.
5. Incorporated the new platform into backup, disaster-recovery, documentation, and support processes.

## Outcome

The modernised platform improved supportability, workload management, capacity, and resilience while establishing a stronger base for production services and future migration work.

Windows Server · Hyper-V · Clustering · Active Directory · Virtual machines · Storage · NAS · LUNs · iSCSI · Migration planning · Service validation · Troubleshooting
